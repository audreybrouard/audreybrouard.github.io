J’ai eu l’occasion d’écrire un retour d’expérience sur l’introduction de GitHub Copilot au sein de la DSI d’Harmonie Mutuelle.

L’article revient sur notre démarche d’expérimentation : l’implication des développeurs, les usages testés, les bénéfices observés, mais aussi les limites, les questions de sécurité et les conditions nécessaires pour accompagner l’adoption de l’outil.
Une première expérience qui a ensuite conduit à l’activation de GitHub Copilot Business dans la DSI.
