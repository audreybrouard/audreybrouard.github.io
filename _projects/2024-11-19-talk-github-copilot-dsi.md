J’ai eu l’occasion de partager notre retour d’expérience autour de GitHub Copilot lors du FROG - French Octocat Group, la communauté française des utilisateurs de GitHub, qui se retrouve pour partager pratiques, usages et retours d’expérience.

Petit challenge supplémentaire : le talk était en anglais. 🇬🇧

L’objectif n’était pas de présenter GitHub Copilot ou ses fonctionnalités, mais de raconter ce qui se passe quand on essaie réellement de déployer ce type d’outil à l’échelle d’une DSI.

J’y ai partagé notre approche pour intégrer Copilot progressivement, embarquer les développeurs dans l’expérimentation et, surtout, répondre à une question qui s’est révélée bien plus complexe qu’elle n’en a l’air :

comment mesurer la valeur apportée par Copilot sans réduire la productivité d’un développeur à un nombre de lignes de code ?
